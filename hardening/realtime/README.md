# Realtime Hardening

## Initial Use Cases

- Inventory changes
- Order status
- Payment status
- POS synchronization
- Dashboard updates

## Requirements

- Tenant-aware subscriptions
- Kernel authorization
- Connection limits
- Backpressure
- Reconnect support
- Event ordering where required
- Observability
- Connection metering

## Rule

Realtime must not become the authoritative source of business state.
