# Production Observability

## Required Telemetry

- Structured logs
- Metrics
- Distributed traces
- Health checks
- Readiness checks
- Dependency health
- Queue depth
- Job failures
- Webhook failures
- Payment reconciliation
- Database performance

## Required Context

- request_id
- correlation_id
- organization_id
- project_id
- environment_id
- service
- operation
- duration
- status

## Rule

Every production alert must have an owner and documented response procedure.
