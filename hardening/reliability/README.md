# Reliability Engineering

## Targets

### MVP
Uptime >= 99.5%

### Phase 2
Uptime >= 99.9%

### Phase 3
Uptime >= 99.95%

### Enterprise
Uptime >= 99.99%

## Core Practices

- Timeouts
- Bounded retries
- Circuit breakers
- Idempotency
- Backpressure
- Graceful degradation
- Dependency isolation
- Rollback
- Failure testing
- Capacity monitoring

## Rule

Retries must never be infinite.
