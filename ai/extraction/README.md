# AI Extraction

## Purpose

Convert unstructured content into validated structured data.

## Use Cases

- Invoices
- Receipts
- Product documents
- Supplier documents
- Support messages
- Contracts
- Reports

## Pipeline

Document
→ Preprocessing
→ Extraction
→ Schema Validation
→ Confidence Evaluation
→ Human Review if Required
→ Persistence
→ Audit

## Rule

Low-confidence or material financial extraction must support human verification.
