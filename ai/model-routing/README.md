# Model Routing

## Purpose

Select the appropriate model based on task, cost, latency, capability, policy, and availability.

## Routing Factors

- Task type
- Required capability
- Latency target
- Cost budget
- Context size
- Data sensitivity
- Provider availability
- Tenant policy
- Model quality

## Routing Strategy

Request
→ Task Classification
→ Policy Constraints
→ Candidate Models
→ Score
→ Select
→ Execute
→ Measure

## Future Capabilities

- Fallback routing
- Cost optimization
- Quality scoring
- Load balancing
- Multi-model consensus
