# AI Governance

## Governance Areas

- Model approval
- Data classification
- Privacy
- Tenant isolation
- Prompt security
- Output validation
- Human approval
- Cost controls
- Audit
- Incident response

## Risk Levels

LOW
- Drafting
- Summarization
- Search assistance

MEDIUM
- Recommendations
- Forecasting
- Automated classification

HIGH
- Financial actions
- Customer-impacting state changes
- Security-sensitive operations
- External communications with material impact

## Rule

High-risk actions require explicit authorization and appropriate approval controls.
