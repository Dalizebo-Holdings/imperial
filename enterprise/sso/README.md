- SAML 2.0
- OpenID Connect
- SCIM

## Capabilities

- Identity provider configuration
- Domain verification
- Just-in-time provisioning
- SCIM provisioning
- Role mapping

- Session policies
- MFA enforcement

- Tenant isolation
- Fail-closed authorization
- Audit logging
- Break-glass access procedures
