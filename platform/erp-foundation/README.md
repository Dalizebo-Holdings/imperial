# ERP Foundation

## Purpose

Build ERP capabilities by composing existing Dalizebo platform domains.

## Reused Domains

- Identity
- CRM
- Commerce
- POS
- Inventory
- Payments
- Billing
- Analytics
- Projects
- Automate
- Audit

## Initial ERP Modules

- Procurement
- Suppliers
- Purchase Orders
- Inventory Operations
- Expense Tracking
- Approvals
- Basic Finance Operations
- Operational Reporting

## Principle

ERP must not recreate existing platform domains.

It extends and coordinates them.
