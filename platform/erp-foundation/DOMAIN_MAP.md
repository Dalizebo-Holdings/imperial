# ERP Domain Map

## Existing Authority

Customer → Kernel Customer Domain

Product → Kernel Catalog Domain

Inventory → Kernel Inventory Domain

Order → Kernel Order Domain

Payment → Kernel Payment Domain

Billing → Billing Platform

Identity → Kernel Identity Domain

## New ERP Domains

- Supplier
- Purchase Order
- Procurement Request
- Goods Receipt
- Expense
- Approval
- Cost Center

## Rule

ERP introduces only genuinely new authoritative business entities.
