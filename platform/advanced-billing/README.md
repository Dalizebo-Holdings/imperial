# Advanced Billing

## Capabilities

- Subscription plans
- Seat billing
- Usage billing
- Product bundles
- Add-ons
- Credits
- Discounts
- Trials
- Proration
- Invoices
- Tax metadata
- Payment retries
- Entitlements

## Billing Model

Account
→ Subscription
→ Products
→ Entitlements
→ Usage
→ Rating
→ Invoice
→ Payment
→ Reconciliation

## Rule

Entitlements must be derived from authoritative billing state.
