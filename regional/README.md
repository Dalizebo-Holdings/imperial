# Dalizebo Regional Platform

## Purpose

Extend Dalizebo into multiple regional markets while preserving one platform architecture, one control plane, shared Kernel contracts, and region-specific data planes.

## Architecture

Global Control Plane
→ Regional Data Planes
→ Dalizebo BaaS
→ Dalizebo SaaS
→ Regional Integrations

## Initial Regional Targets

- South Africa
- Botswana
- Lesotho
- Eswatini
- Namibia
- Zimbabwe
- Mozambique

## Core Principle

Regional differences belong in configuration, adapters, policy, and data-plane deployment—not incompatible product forks.
