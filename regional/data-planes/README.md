# Regional Data Planes

## Responsibilities

Each regional data plane may provide:

- Database
- Storage
- Functions
- Events
- Realtime
- Payments
- Logs
- Backups
- Regional integrations

## Provisioning Model

Organization
→ Residency Policy
→ Selected Region
→ Regional Data Plane

## Requirements

- Standard Kernel contracts
- Standard APIs
- Tenant isolation
- Region-aware secrets
- Region-aware backups
- Observability
- Disaster recovery
