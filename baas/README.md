# Dalizebo Backend

Dalizebo Backend is the Backend-as-a-Service layer built on top of the Dalizebo Kernel.

## Architecture

Pillars OS
→ 269 Operating Systems
→ Algorithm OS + Loop OS + Integrations OS
→ Dalizebo Kernel
→ Dalizebo Backend
→ Dalizebo SaaS

- Authentication
- PostgreSQL Database
- Object Storage
- Serverless Functions
- API Gateway

- Webhooks
- Background Jobs
- Audit

- Usage Metering
- Subscription Billing
- Payment Abstraction
- Secrets
