# Dalizebo Ecosystem

## Purpose

The Dalizebo Ecosystem connects customers, developers, partners, service providers, and regional operators around the Dalizebo platform.

## Participants

- Customers
- Merchants
- Developers
- Implementation Partners
- Resellers
- Payment Providers
- Logistics Providers
- Technology Partners
- Consultants
- Enterprise Customers

## Architecture

Dalizebo Kernel
→ Dalizebo BaaS
→ Dalizebo SaaS
→ Developer Cloud
→ Marketplace
→ Partner Ecosystem
→ Regional Platform

## Principle

The ecosystem extends Dalizebo through governed contracts, certified integrations, shared incentives, and standardized APIs.
