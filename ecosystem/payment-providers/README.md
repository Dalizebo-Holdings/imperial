# Payment Provider Ecosystem

## Purpose

Support licensed payment providers through standard Dalizebo payment adapters.

## Provider Requirements

- Supported currencies
- Payment methods
- Refund support
- Webhooks
- Settlement information
- Reconciliation
- Availability monitoring
- Support escalation

## Architecture

Dalizebo Payments
→ Payment Adapter
→ Licensed Provider

## Rule

Provider integration must remain behind Dalizebo payment contracts.
