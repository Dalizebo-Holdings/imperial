# Partner APIs

## Purpose

Provide controlled platform access to approved Dalizebo partners.

## API Areas

- Organizations
- Customers
- Products
- Orders
- Inventory
- Payments
- Logistics
- Billing
- Analytics

## Requirements

- Versioned APIs
- OAuth or scoped credentials
- Tenant authorization
- Rate limits
- Audit
- Usage metering

## Rule

Partner APIs must not expose privileged Kernel internals.
