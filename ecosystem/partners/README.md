# Partner Program

## Partner Types

- Implementation Partner
- Integration Partner
- Technology Partner
- Referral Partner
- Reseller
- Regional Partner

## Partner Lifecycle

APPLIED
→ REVIEWED
→ APPROVED
→ ENABLED
→ CERTIFIED
→ ACTIVE

Exception states:

- SUSPENDED
- TERMINATED

## Requirements

Partners must have:

- Verified identity
- Defined capability
- Support ownership
- Commercial agreement where applicable
- Security obligations
- Platform compliance
