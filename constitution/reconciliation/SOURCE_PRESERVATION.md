# Source Preservation Policy

## Immutable Source Artifacts

- source/IMPERIAL_ARCHITECT_RAW.md
- constitution/207_PILLARS_SOURCE.md
- constitution/pillar-registry.csv

## Rules

1. Never silently rewrite an original Pillar.
2. Never delete an original Pillar because its canonical interpretation changes.
3. Reframed Pillars retain the original statement alongside the canonical version.
4. Retired Pillars remain visible for historical and audit purposes.
5. Every reconciliation decision requires a reason.
6. Implementation references must point to the approved canonical interpretation.
