# Pillar Reconciliation Standard

## Purpose

Reconcile the 207 original Imperial Architect Pillars into an implementable constitutional layer while preserving every original source statement unchanged.

## Approved Classifications

### KEEP
Retain as a constitutional strategic principle.

### POLICY
Implement primarily through Pillars OS, governance, compliance, SOPs, or organizational policy.

### TECHNICAL
Translate into enforceable Kernel, BaaS, security, infrastructure, API, data, or architecture controls.

### R&D
Preserve as a long-term research objective rather than current production architecture.

### REFRAME
Preserve the original statement but create a lawful, ethical, commercially legitimate canonical interpretation.

### RETIRE
Preserve historically but prohibit implementation.

## Source Preservation Rule

The original source statement must never be overwritten.

Canonical interpretations, technical controls, and implementation policies must exist as separate fields or documents.

## Approval Rule

A Pillar is not considered reconciled until approved_classification is no longer UNREVIEWED.
