# Dalizebo POS

Dalizebo POS provides in-store transaction and branch operations on the shared Dalizebo platform.

## P0 Capabilities

- Branches
- Staff
- Roles
- Product search
- Barcode and SKU lookup
- Cart
- Checkout
- Cash payment recording
- Card payment recording
- Receipts
- Inventory deduction
- Returns
- Daily summaries

## P1 Capabilities

- Offline queue
- Receipt printers
- Cash drawer reconciliation
- Stock transfers
- Staff reporting
- Purchase history

## Architecture

Dalizebo POS
→ Dalizebo Backend
→ Dalizebo Kernel
→ Shared Commerce Primitives
