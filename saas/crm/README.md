# Dalizebo CRM

## Purpose

Dalizebo CRM manages customer relationships using the shared Dalizebo customer model.

## P0 Capabilities

- Customer profiles
- Segmentation
- Activities
- Notes
- Sales pipeline
- Basic campaigns
- Customer history
- Reporting

## Shared Dependencies

- Identity
- Customers
- Orders
- Payments
- Commerce
- POS
- Events
- Analytics

## Rule

CRM must reuse the shared Customer entity and must not create a second authoritative customer database.
