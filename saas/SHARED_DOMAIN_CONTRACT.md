# Shared SaaS Domain Contract

## Shared Authoritative Entities

- Organization
- Workspace
- User
- Role
- Store
- Branch
- Product
- Product Variant
- Inventory Item
- Customer
- Cart
- Order
- Order Item
- Payment
- Refund
- Discount
- Audit Event

## Rule

SaaS products consume these entities through Kernel and BaaS contracts.

They must not create separate authoritative copies.
