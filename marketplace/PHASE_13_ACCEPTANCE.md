# Phase 13 Acceptance Criteria

## Developer

- Publishers can register
- Applications can be submitted
- Versions can be released
- Permissions are declared
- Sandboxes are available

## Security

- Automated scanning operational
- Permission review operational
- Extension revocation supported
- No direct Kernel access

## Customer

- Apps can be discovered
- Install permissions are visible
- Apps can be installed
- Apps can be revoked
- Billing works
- Ratings work

## Platform

- Marketplace APIs are versioned
- Revenue allocation is auditable
- Extension activity appears in audit records
