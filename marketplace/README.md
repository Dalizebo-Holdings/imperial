# Dalizebo Marketplace

## Purpose

The Dalizebo Marketplace allows third-party developers and partners to extend the platform without modifying the Dalizebo Kernel.

## Marketplace Assets

- Apps
- Plugins
- Themes
- Connectors
- Workflows
- AI Agents
- Functions
- Dashboards

## Architecture

Developer
→ Developer Cloud
→ Marketplace
→ Review & Security
→ Installation
→ Dalizebo APIs
→ Dalizebo BaaS
→ Dalizebo Kernel

## Core Principle

Marketplace extensions operate through versioned public contracts and explicitly granted permissions.
