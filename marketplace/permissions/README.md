# Marketplace Permission Model

## Principles

- Least privilege
- Explicit consent
- Tenant scope
- Environment scope
- Revocable access
- Auditability

## Permission Categories

- Identity
- Customers
- Products
- Inventory
- Orders
- Payments
- Billing
- Storage
- Events
- Analytics
- Automation

## Rule

An extension may access only permissions explicitly approved during installation.
