# Marketplace Review Pipeline

## Review Stages

Submission
→ Automated Validation
→ Security Scan
→ Permission Review
→ Functional Review
→ Policy Review
→ Approval

## Automated Checks

- Manifest validation
- Permission analysis
- Dependency scanning
- Secret scanning
- Malware detection
- Known vulnerability scanning
- API compatibility

## Manual Review

Required where an extension:

- Processes payments
- Handles sensitive data
- Requests privileged permissions
- Uses AI agents for material actions
