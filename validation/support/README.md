# Pilot Support

## Severity Levels

### P0
Critical outage, security incident, cross-tenant exposure, data-loss risk.

### P1
Major business workflow unavailable.

### P2
Degraded functionality with workaround.

### P3
Minor defect or usability issue.

## Pilot Target

P1 first response within one business day.

## Every Ticket Must Record

- Merchant
- Organization ID
- Severity
- Product
- Environment
- Description
- Correlation ID
- Owner
- Resolution
