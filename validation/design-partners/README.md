# Design Partners

## Target

- 20–30 discovery interviews
- 5–10 design partner commitments
- Minimum 3 active pilot merchants

## Selection Criteria

Partners should have:

- Active retail operations
- Real inventory
- Real customers
- Transaction volume
- Willingness to test Commerce and/or POS
- Ability to provide structured feedback

## Required Validation

At least 80% of interviewed merchants should confirm the core problem is material.
