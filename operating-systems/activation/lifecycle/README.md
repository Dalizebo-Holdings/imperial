# OS Activation Lifecycle

## DEFINED

The capability has:

- OS ID
- Name
- Purpose
- Scope

## CLASSIFIED

The OS has:

- Domain
- Implementation type
- Priority
- Security level
- Roadmap phase

## MODELLED

The OS has:

- Inputs
- Outputs
- Data model
- Dependencies
- Events
- Interfaces
- Policies

## PROTOTYPED

A controlled proof of concept exists.

## IMPLEMENTED

Production-capable implementation exists.

## INTEGRATED

The OS works through standard Dalizebo platform contracts.

## AUTOMATED

Repeatable execution is automated through Loop OS or equivalent orchestration.

## MEASURED

Operational and business metrics are collected.

## OPTIMIZED

Performance, reliability, cost, usability, and outcomes are continuously improved.
