# Operating System Registry Schema

Every Operating System must contain:

- os_id
- name
- domain
- description
- owner
- status
- priority
- implementation_type
- roadmap_phase
- security_level
- dependencies
- pillar_dependencies
- inputs
- outputs
- data
- APIs
- events
- policies
- integrations
- metrics
- risks
- compliance_requirements
- last_reviewed_at
