# Operating Systems Classification

## Domains

| Domain | Purpose |
|--------|---------|
| Finance & Capital | Money, treasury, investment, billing, tax |
| Commerce & Retail | Products, stores, orders, inventory, POS |
| Payments & Billing | Checkout, payments, refunds, subscriptions |
| Identity & Security | Users, access, permissions, tenant isolation |
| Data & Knowledge | Files, documents, records, knowledge systems |
| AI & Intelligence | AI gateway, analytics, forecasting, agents |
| Automation & Workflow | Loops, jobs, workflows, process automation |
| Legal & Compliance | Contracts, audit, regulation, approvals |
| Marketing & Customer | CRM, campaigns, support, retention |
| Operations & Logistics | Delivery, stock movement, branch operations |
| Infrastructure & Cloud | Compute, storage, networking, deployment |
| Developer Platform | APIs, SDKs, CLI, docs, marketplace |
| Governance & Audit | Pillars OS, policy, evidence, compliance |
| Frontier R&D | Long-term research and speculative systems |

---

## Implementation Types

| Type | Meaning |
|------|---------|
| CORE | Kernel or BaaS primitive |
| PRODUCT | SaaS product module |
| SHARED_SERVICE | Reusable internal platform service |
| POLICY | Governance or compliance rule |
| INTEGRATION | External connector |
| AUTOMATION | Workflow, job, loop, or trigger |
| DATA_PRODUCT | Reporting, analytics, knowledge model |
| R&D | Future research |
| RETIRED_REFRAMED | Unsafe, unlawful, impractical, or not useful as written |
