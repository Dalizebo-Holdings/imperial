# Post-Quantum Security

## Purpose

Prepare Dalizebo for future cryptographic migration without prematurely replacing proven production cryptography.

## Research Areas

- Cryptographic inventory
- Algorithm agility
- Key lifecycle
- Certificate migration
- Hybrid cryptographic models
- Data requiring long-term confidentiality

## Principle

Cryptographic agility should be designed into the platform before post-quantum migration becomes operationally necessary.
