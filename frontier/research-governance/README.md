# Research Governance

## Every Research Initiative Must Define

- Research ID
- Owner
- Hypothesis
- Strategic relevance
- Budget
- Timeline
- Risks
- Dependencies
- Success criteria
- Exit criteria

## Lifecycle

PROPOSED
→ APPROVED
→ RESEARCHING
→ PROTOTYPED
→ VALIDATED

Then either:

VALIDATED
→ PRODUCTIZATION_REVIEW

or:

VALIDATED
→ ARCHIVED

## Rule

Research does not become production architecture automatically.
