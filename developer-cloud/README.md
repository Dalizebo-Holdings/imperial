# Dalizebo Developer Cloud

## Purpose

Dalizebo Developer Cloud exposes the Dalizebo platform to external developers through stable APIs, SDKs, CLI tooling, projects, environments, logs, usage visibility, and deployment workflows.

## Architecture

Developer
→ Developer Cloud
→ Dalizebo BaaS
→ Dalizebo Kernel
→ Pillars OS

## Core Capabilities

- Developer Dashboard
- Public APIs
- CLI
- SDKs
- API Keys
- Projects
- Environments
- Sandboxes
- Logs
- Usage Metrics
- Deployments
- Documentation
- Examples

## Platform Principle

External developers consume versioned platform contracts and must never depend directly on internal implementation details.
